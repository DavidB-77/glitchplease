# Glitch, please. uploader

This is the home page for the "Glitch please uploader", a small private tool used by the owner of the Glitch, please. fact-check channel (YouTube: GlitchPleaseTV, TikTok and X: @glitchpleasehq).

The tool runs on the channel owner's own computer. It uses the YouTube Data API to upload the channel's own videos, set their thumbnails, and post comments on them. It is not offered to the public, and nobody else signs in to it.
