# Privacy policy: Glitch please uploader

Last updated: November 8, 2026

The Glitch please uploader is a private tool used only by the owner of the Glitch, please. YouTube channel, on the owner's own computer, to manage that one channel.

## What it accesses

With the channel owner's permission, the tool uses Google's YouTube Data API (scopes youtube.upload and youtube.force-ssl) to upload videos to the channel, set their thumbnails and details, and post comments on the channel's own videos.

## What it stores

The sign-in token Google issues is saved only on the channel owner's computer. The tool keeps no database, runs no server, and collects no data about viewers or anyone else.

## Sharing

No data from Google accounts or YouTube is sold, shared, or transferred to anyone. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access

Access can be removed at any time at https://myaccount.google.com/permissions, which ends the tool's ability to use the account.
